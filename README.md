# Admin Button System

A versatile admin tool for FiveM servers with button-based actions.

## Features

- Button-based admin interface
- Player management actions (revive, kick, ban)
- Logging of admin actions

## Requirements

- FiveM server
- ESX Framework
- MySQL database

## Installation

1. Download the script files.
2. Place them in your FiveM server's resources folder.
3. Add `start adminButtonSystem` to your server.cfg file.
4. Import the database.sql file into your MySQL database.

## Usage

1. Admins can open the admin menu by pressing the E key while looking at a player.
2. Select the desired action from the menu.

## Configuration

The script can be configured in the `config.lua` file. You can add or remove buttons as needed.
